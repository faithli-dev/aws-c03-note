# RPO and RTO

A disaster is any event that has a negative impact on a company's business continuity or finances. Disaster recovery (DR) is about preparing for and recovering from a disaster.

## Types of DR

- On-premises → on-premises: traditional DR, very expensive.
- On-premises → AWS Cloud: hybrid recovery.
- AWS Cloud Region A → AWS Cloud Region B.

## Definitions

- **RPO (Recovery Point Objective)** – how much data loss is acceptable. The point in time to which data must be restored.
- **RTO (Recovery Time Objective)** – how much downtime is acceptable. The time to restore service.
