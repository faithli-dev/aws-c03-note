# Aurora Machine Learning

Aurora Machine Learning adds ML-based predictions to applications using SQL.

## Characteristics

- Simple, optimised, and secure integration between Aurora and AWS ML services.
- No ML experience required.

## Supported Services

- **Amazon SageMaker** – use with any ML model.
- **Amazon Comprehend** – sentiment analysis.

![[SAA-v48-p178-aurora-ml.png]]

## Use Cases

- Fraud detection
- Ads targeting
- Sentiment analysis
- Product recommendations
