# Babelfish for Aurora PostgreSQL

Babelfish lets Aurora PostgreSQL understand commands targeted at Microsoft SQL Server (T-SQL).

## Benefit

- Microsoft SQL Server based applications can run on Aurora PostgreSQL.
- Requires no or little code change: the same MS SQL Server client driver can be used.
- The same applications can be used after a database migration with AWS SCT and DMS.
