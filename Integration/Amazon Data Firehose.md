# Amazon Data Firehose

Formerly called Kinesis Data Firehose.

## Characteristics

- Fully managed service.
- Destinations: Amazon Redshift, Amazon S3, Amazon OpenSearch Service, third-party services (Splunk, MongoDB, Datadog, NewRelic), and custom HTTP endpoints.
- Automatic scaling, serverless, pay for what you use.
- Near real-time with buffering capability based on size or time.
- Supports CSV, JSON, Parquet, Avro, raw text, and binary data.
- Conversions to Parquet / ORC and compression with gzip / snappy.
- Custom data transformations using AWS Lambda, for example CSV to JSON.
