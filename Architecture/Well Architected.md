# AWS Well-Architected Framework

The Well-Architected Framework reviews workloads against six connected pillars:

1. Operational Excellence
2. Security
3. Reliability
4. Performance Efficiency
5. Cost Optimization
6. Sustainability

General principles include stopping capacity guessing, testing at production scale, automating experimentation, allowing evolutionary architecture, using data to drive decisions, and running game days.

![[SAA-v48-p855-well-architected-pillars.png]]

Use the Well-Architected Tool to answer workload questions, review risks, generate guidance, and track improvements. Trusted Advisor provides account-level recommendations across cost, performance, security, fault tolerance, service limits, and operational excellence.
