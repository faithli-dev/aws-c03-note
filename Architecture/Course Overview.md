# Course Overview

The deck prepares learners for the AWS Certified Solutions Architect Associate (SAA-C03) exam. It assumes basic IT knowledge and builds from AWS fundamentals into architecture patterns across more than 30 services.

![[SAA-v48-p012-aws-spaghetti.png]]

## Study Map

- **Foundations:** [[Infrastructure/Getting Started]], [[Infrastructure/Global Infrastructure]], IAM, and core networking.
- **Compute:** EC2, Elastic Load Balancing, Auto Scaling, Elastic Beanstalk, containers, and Lambda.
- **Storage and databases:** S3, EBS, EFS, FSx, RDS, Aurora, DynamoDB, ElastiCache, and specialized databases.
- **Integration and serverless:** SQS, SNS, Kinesis, EventBridge, Step Functions, API Gateway, and Cognito.
- **Security and operations:** KMS, CloudTrail, Config, CloudWatch, Systems Manager, WAF, Shield, and GuardDuty.
- **Architecture decisions:** high availability, scalability, disaster recovery, migration, cost control, and the Well-Architected Framework.

Use [[AWS Certified Solutions Architect Associate]] as the topic index. Each linked note summarizes exam-relevant concepts, service trade-offs, and architecture patterns from the corresponding slide range.
