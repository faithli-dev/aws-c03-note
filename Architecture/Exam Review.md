# SAA-C03 Exam Review

## State of Learning

Check the official AWS Certified Solutions Architect – Associate page for the current exam guide.

## Practice

- If you are new to AWS, take time for practice before rushing to the exam.
- The exam recommends one or more years of hands-on experience on AWS.
- If you feel overwhelmed, go through the material one more time.

## Proceed by Elimination

- Most questions are scenario based.
- Rule out answers you know are wrong.
- For the remaining answers, understand which makes the most sense.
- There are very few trick questions; do not overthink.
- If a solution seems feasible but highly complicated, it is probably wrong.

## Study Resources

- Skim AWS whitepapers: Architecting for the Cloud, AWS Well-Architected Framework, AWS Disaster Recovery.
- Read each service's FAQ; FAQs cover many exam questions and confirm your understanding.
- Get into the AWS community: course Q&A, practice tests, forums, blogs, local meetups, and re:Invent videos.

## Exam Format

- Register online at AWS Training.
- Fee: $150 USD.
- Provide one identity document (ID or passport).
- No notes, no pen, no speaking.
- 65 questions in 130 minutes.
- Use the "Flag" feature to mark questions to revisit.
- At the end you can optionally review all questions and answers.
- Pass score: at least 720 out of 1000.
- You will know within 5 days if you passed (usually less).
- The overall score arrives by email a few days later.
- You will not know which answers were right or wrong.
- If you fail, you can retake the exam 14 days later.

## Certification Levels

- **Foundational** – knowledge-based certification for a foundational understanding of the AWS Cloud; no prior experience needed.
- **Associate** – role-based certifications that showcase your knowledge and skills on AWS; prior cloud or strong on-premises IT experience recommended.
- **Professional** – role-based certifications validating advanced skills to design secure, optimised, and modernised applications and automate processes; 2 years of prior AWS Cloud experience recommended.
- **Specialty** – dive deeper and position yourself as a trusted advisor in strategic areas.

![[SAA-v48-p867-certification-levels.png]]

## Certification Paths

- **Architecture** – Solutions Architect, Application Architect.
- **Operations** – Systems Administrator, Cloud Engineer.
- **DevOps** – Test Engineer, Cloud DevOps Engineer, DevSecOps Engineer.
- **Security** – Cloud Security Engineer, Cloud Security Architect.
- **Development and Networking** – Software Development Engineer, Network Engineer.
- **Data Analytics and AI/ML** – Cloud Data Engineer, Machine Learning Engineer, Prompt Engineer, Machine Learning Ops Engineer, Data Scientist.
