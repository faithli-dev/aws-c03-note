# Trusted Advisor

A high-level AWS account assessment with no installation needed.

## Categories

Analyses your AWS accounts and provides recommendations in 6 categories:

- Cost optimization
- Performance
- Security
- Fault tolerance
- Service limits
- Operational Excellence

![[SAA-v48-p857-trusted-advisor.png]]

## Support Plans

- The full set of checks requires the Business or Enterprise Support plan.
- Programmatic access is available using the AWS Support API.
