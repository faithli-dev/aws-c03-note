# Amazon Macie

A fully managed data security and data privacy service that uses machine learning and pattern matching to discover and protect sensitive data in AWS.

## Characteristics

- Helps identify and alert you to sensitive data such as personally identifiable information (PII).
- Analyses S3 buckets.
- Sends findings to Amazon EventBridge for integrations.
