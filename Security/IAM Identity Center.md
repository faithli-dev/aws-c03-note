# AWS IAM Identity Center

IAM Identity Center, formerly AWS Single Sign-On, provides one login for AWS accounts, business applications, SAML 2.0 applications, and supported EC2 Windows workflows.

- Identities can live in the built-in directory or come from Active Directory or another identity provider.
- Permission Sets are collections of IAM policies assigned to users or groups for selected AWS accounts.
- Organizations provides the account and OU structure; Identity Center provides the human sign-in and account assignments.
- Use groups and short-lived role sessions instead of creating long-lived IAM users in every account.
