# Sticky Sessions

Sticky sessions (session affinity) make the same client always redirect to the same instance behind a load balancer.

## Behaviour

- Works for CLB, ALB, and NLB.
- For CLB and ALB, the cookie used for stickiness has an expiration date you control.
- Use case: make sure the user does not lose session data.
- Enabling stickiness can bring imbalance to the load on backend EC2 instances.

## Cookie Names

### Application-based cookies

- **Custom cookie** – generated by the target; can include custom attributes. The cookie name must be specified per target group. Do not use `AWSALB`, `AWSALBAPP`, or `AWSALBTG` (reserved by ELB).
- **Application cookie** – generated by the load balancer; cookie name is `AWSALBAPP`.

### Duration-based cookies

- Generated by the load balancer.
- Cookie name is `AWSALB` for ALB and `AWSELB` for CLB.
