# EKS Data Volumes

- Specify a StorageClass manifest on your EKS cluster.
- Leverages a Container Storage Interface (CSI) compliant driver.
- Supported storage:
	- Amazon EBS
	- Amazon EFS (works with Fargate)
	- Amazon FSx for Lustre
	- Amazon FSx for NetApp ONTAP
