# Good Metrics to Scale On

## Common Metrics

- **CPUUtilization** – average CPU utilisation across instances.
- **RequestCountPerTarget** – keeps the number of requests per EC2 instance stable.
- **Average Network In / Out** – for network-bound applications.
- Any **custom metric** pushed through CloudWatch.
