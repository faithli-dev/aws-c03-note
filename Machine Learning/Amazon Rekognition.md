# Amazon Rekognition

Find objects, people, text, and scenes in images and videos using machine learning.

## Capabilities

- Facial analysis and facial search for user verification and people counting.
- Create a database of "familiar faces" or compare against celebrities.

![[SAA-v48-p561-rekognition.png]]

## Use Cases

- Labelling
- Content moderation
- Text detection
- Face detection and analysis (gender, age range, emotions)
- Face search and verification
- Celebrity recognition
- Pathing, for example sports game analysis

## Content Moderation

- Detects content that is inappropriate, unwanted, or offensive in images and videos.
- Used in social media, broadcast media, advertising, and e-commerce to create a safer user experience.
- Set a minimum confidence threshold for items that will be flagged.
- Flag sensitive content for manual review in Amazon Augmented AI (A2I).
- Helps comply with regulations.
