# Amazon SageMaker AI

Fully managed service for developers and data scientists to build ML models.

## Why It Exists

It is typically difficult to do all the machine learning processes in one place and provision servers.

## Simplified Process

1. Historical data (for example years of IT experience, years of AWS experience, time spent on the course) with a label (exam score).
2. Build an ML model.
3. Train and tune the model.
4. Apply the model to new data to get a prediction.
