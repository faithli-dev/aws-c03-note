# Amazon Kendra

Fully managed document search service powered by machine learning.

## Characteristics

- Extracts answers from within a document (text, PDF, HTML, PowerPoint, MS Word, FAQs).
- Natural language search capabilities.
- Learns from user interactions and feedback to promote preferred results (incremental learning).
- Ability to manually fine-tune search results (importance of data, freshness, custom).

![[SAA-v48-p571-kendra.png]]

## Data Sources

Amazon S3, Amazon RDS, Google Drive, Microsoft SharePoint, Microsoft OneDrive, third-party sources, and custom connectors. Content is indexed into a knowledge index powered by ML.
