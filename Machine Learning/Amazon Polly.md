# Amazon Polly

Turn text into lifelike speech using deep learning, allowing you to create applications that talk.

## Lexicon and SSML

- Customise pronunciation of words with pronunciation lexicons:
	- Stylised words: `St3ph4ne` → "Stephane"
	- Acronyms: `AWS` → "Amazon Web Services"
- Upload lexicons and use them in the `SynthesizeSpeech` operation.
- Generate speech from plain text or from documents marked up with Speech Synthesis Markup Language (SSML) for more customisation:
	- Emphasising specific words or phrases
	- Using phonetic pronunciation
	- Including breathing sounds, whispering
	- Using the Newscaster speaking style
