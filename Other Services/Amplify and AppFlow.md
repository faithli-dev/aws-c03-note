# AWS Amplify and AppFlow

## AWS Amplify
Amplify provides tools and managed services for full-stack web and mobile applications.

- Amplify can configure authentication, storage, REST or GraphQL APIs, Pub/Sub, analytics, AI/ML integrations, monitoring, and CI/CD.
- Amplify Console builds and deploys frontends from GitHub, CodeCommit, Bitbucket, or GitLab and uses S3 and CloudFront for delivery.
- Amplify libraries connect the frontend to Cognito, AppSync, API Gateway, Lambda, DynamoDB, S3, and other services.

## Amazon AppFlow
- AppFlow transfers data securely between SaaS sources such as Salesforce, SAP, Zendesk, Slack, and ServiceNow and destinations such as S3, Redshift, Snowflake, or Salesforce.
- Flows can run on demand, on a schedule, or in response to events.
- Built-in filtering, validation, transformation, encryption, and PrivateLink connectivity reduce custom integration code.
