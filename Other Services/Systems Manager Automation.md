# Systems Manager Automation

Simplifies common maintenance and deployment tasks of EC2 instances and other AWS resources. Examples: restart instances, create an AMI, take an EBS snapshot.

## Automation Runbook

SSM documents that define actions performed on your EC2 instances or AWS resources (predefined or custom).

## Triggers

- Manually using the AWS Console, AWS CLI, or SDK
- Amazon EventBridge
- On a schedule using Maintenance Windows
- By AWS Config for rule remediations
