# Edge Computing

Process data while it is being created at an edge location, such as a truck on the road, a ship at sea, or a mining station underground. These locations may have limited internet and no access to computing power.

## Snowball Edge for Edge Computing

- Set up a Snowball Edge device to do edge computing.
- Use Snowball Edge Compute Optimized (dedicated to this use case) or Storage Optimized.
- Run EC2 instances or Lambda functions at the edge.

![[SAA-v48-p354-edge-computing.png]]

## Use Cases

- Preprocess data
- Machine learning
- Media transcoding
