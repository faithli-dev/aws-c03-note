# Tape Gateway

Some companies have backup processes using physical tapes. Tape Gateway keeps the same processes but moves them to the cloud.

## Behaviour

- Virtual Tape Library (VTL) backed by Amazon S3 and Glacier.
- Back up data using existing tape-based processes and an iSCSI interface.
- Works with leading backup software vendors.
