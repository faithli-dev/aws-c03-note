# Route 53 Routing Policies

Routing policies define how Route 53 responds to DNS queries. Do not confuse this with load balancer routing: DNS does not route traffic, it only responds to queries.

## Policies

- Simple
- Weighted
- Failover
- Latency-based
- Geolocation
- Geoproximity (using the Route 53 Traffic Flow feature)
- IP-based
- Multi-Value Answer
